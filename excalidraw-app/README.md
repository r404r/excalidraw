
# Excalidraw Desktop Application Development

## Personal Modifications and Tauri Experiment

This is a set of modifications based on my personal interests, in order to use this application without relying on the internet. This is also my first attempt at using Tauri.

I have updated the TypeScript version to 5.4.5 and the React version to 19.1.0. Due to these modifications, some source code files were unable to compile, so I made some minor adjustments, but did not perform comprehensive functional testing.

The recommended Node.js version is v20.19.1. On Windows 11, I use nvm to manage multiple Node.js versions.
